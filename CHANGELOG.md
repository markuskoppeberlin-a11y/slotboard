# Changelog

## 0.1.0 – first test version

- ⌘C + digit stores the clipboard in one of ten slots, ⌘V + digit pastes it (Ctrl on Windows/Linux).
- Slots keep every clipboard format (text, formatted text, images, files, app content).
- The normal clipboard is restored after pasting from a slot.
- Menu bar / tray menu with the slot list, pause, open at login.
- Guided setup in German and English, including macOS keyboard access.
